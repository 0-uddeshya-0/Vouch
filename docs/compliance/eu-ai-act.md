# EU AI Act — Transparency Notes

Vouch is an AI-assisted code review tool. Under the EU AI Act it falls under the
transparency obligations for limited-risk AI systems (Article 50): people
interacting with it must be able to tell that analysis was produced by an AI
system.

This document describes what Vouch actually does today — not aspirational
compliance claims. Nothing here constitutes legal advice; if you deploy Vouch
commercially in the EU, have counsel review your obligations.

## What Vouch implements

**AI disclosure in every output.** Every PR comment ends with a footer stating
the analysis was generated by Vouch and naming the analysis method — either
"deterministic AST parsing and registry verification (no LLM inference on this
run)" or the specific model used. Check-run summaries name the model as well.

**Deterministic findings are separated from AI findings.** Hallucination,
secret, and CVE findings come from registry lookups, pattern matching, and the
OSV database — they are reproducible and carry evidence (the package name, the
matched line, the CVE ID). LLM findings carry a confidence score and are
clearly typed.

**Human oversight.** No finding blocks a merge by itself; Vouch posts a check
run that maintainers can override, and the dashboard provides one-click
dismissal with the dismissing user and timestamp recorded on the finding
(`dismissedBy`, `dismissedAt` in the database).

**Event logging.** Webhook receipt, signature verification, analysis start and
completion, and dismissals are logged as structured JSON to stdout, suitable
for shipping to your log aggregator.

## What Vouch does not implement (yet)

- Audit log export tooling (logs are stdout JSON; retention is up to your
  logging infrastructure)
- Calibration/accuracy reporting on LLM confidence scores
- Conformity assessment artifacts

If your deployment needs these, track them as deployment requirements rather
than assuming the tool provides them.
